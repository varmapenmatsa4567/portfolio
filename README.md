# chiranjeevipenmatsa.com

Personal portfolio landing page for Chiranjeevi Varma Penmatsa — React + Vite, dark interactive design.

## Features
- Animated particle-constellation hero that reacts to the mouse
- Typewriter role cycler, gradient name, scroll-fade parallax
- 3D tilt project cards (AI Whiteboard, VirtualOS, Pocket Todos)
- Tech marquee strip, skills grid, journey timeline, contact section
- Framer Motion scroll reveals; responsive down to mobile

## Run
```bash
npm install
npm run dev      # local dev
npm run build    # static build into dist/
npm run preview  # preview the build
```

## Deploy (Vercel)
Import the repo in Vercel — framework preset "Vite", build `npm run build`, output `dist`. No env vars needed.
